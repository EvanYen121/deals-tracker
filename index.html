Private data, loaded with your GitHub token.

This page reads its data from a private GitHub repo, so it needs a GitHub token from an account that has access.

  1. Accept the invite to the repo if you haven't.
  2. Create a token (classic, repo scope, any expiry). The repo owner can use a fine-grained token limited to that repo with Contents read/write instead.
  3. Paste it below. It stays in this browser and is only sent to api.github.com.
